# CRX Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a standalone local-first CRX Lab workspace that downloads a Chrome Web Store package and inspects a user-selected extracted manifest.

**Architecture:** Keep package retrieval in the existing narrow Vercel redirect endpoint. Move manifest parsing, normalisation, risk copy, and export generation into a small browser-side helper so it is locally testable and does not expand the server trust boundary. The monolithic static viewer will mount CRX Lab as an independent workspace and use the existing toast system for receipts.

**Tech Stack:** Static HTML/CSS/JavaScript, Vercel serverless redirect endpoint, Vitest/Node for pure-helper unit tests.

- [ ] **Step 3: Implement the minimal pure helper**

```js
(function (root, factory) {
  const api = factory();
  if (typeof module === 'object' && module.exports) module.exports = api;
  root.CrxLab = api;
})(typeof window !== 'undefined' ? window : globalThis, function () {
  function extractExtensionId(value) {
    const match = String(value || '').toLowerCase().match(/[a-p]{32}/);
    return match ? match[0] : '';
  }
  function inspectManifest(manifest) {
    return { name: String(manifest.name || 'Unnamed extension'), version: String(manifest.version || 'Unknown'), manifestVersion: manifest.manifest_version || 'Unknown', permissions: Array.isArray(manifest.permissions) ? manifest.permissions : [], hostPermissions: Array.isArray(manifest.host_permissions) ? manifest.host_permissions : [], background: manifest.background && manifest.background.service_worker ? 'Service worker: ' + manifest.background.service_worker : 'None declared' };
  }
  function inspectionMarkdown(receipt) { return '# ' + receipt.name + '\n\nVersion: ' + receipt.version + '\n'; }
  return { extractExtensionId, inspectManifest, inspectionMarkdown };
});
```

```js
function downloadCrxReceipt(receipt, format) {
  var value = format === 'json' ? JSON.stringify(receipt, null, 2) : CrxLab.inspectionMarkdown(receipt);
  var blob = new Blob([value], { type: format === 'json' ? 'application/json' : 'text/markdown' });
  var link = document.createElement('a');
  link.href = URL.createObjectURL(blob);
  link.download = 'extension-inspection.' + (format === 'json' ? 'json' : 'md');
  link.click();
  setTimeout(function () { URL.revokeObjectURL(link.href); }, 0);
}
```
