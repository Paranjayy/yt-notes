Paste a playlist/queue link, or many individual YouTube video links. Other text is ignored. The keyless route uses public YouTube pages; an optional API key uses the official playlist API.

API key guide — free normal-use quota
  1. Create a Google Cloud project and enable YouTube Data API v3, then create an API key restricted to that API.
  2. Paste it here only when the public playlist route fails; this site does not store it.
  3. Google’s default is 10,000 quota units/day. Playlist pages cost 1 unit each (50 videos/page); video metadata batches cost 1 unit. Quota resets daily at midnight Pacific. Overview · quota reference · playlist endpoint.
